# Amazon Clone

A frontend e-commerce application inspired by Amazon, built to practice building larger interfaces, managing application state, and creating a realistic shopping experience.

The project includes multiple pages that simulate the core flow of an online store, from browsing products to checkout and order tracking.

## Website

**Live Demo:**  
https://nikolozwdev.github.io/Amazon-clone/amazon.html

## About

This project recreates the shopping experience of a modern e-commerce platform with a strong focus on usability and responsive design.

Users can browse products, manage their cart, complete the checkout process, review previous orders, and track deliveries through dedicated pages. Product information is loaded dynamically, while the interface is designed to remain consistent across the application.
